# Сублимационен 3D конфигуратор — План (v2)

## Цел

Брандирана страница `configurator-sublimation.html` с SAVOV PRO дизайн, където клиентът:
- Вижда реалистичен 3D preview на чашата с неговия дизайн
- Качва лого/изображение и добавя текст
- Избира цвят на чашата, дръжката и вътрешността
- Изпраща директно запитване към SAVOV PRO (WhatsApp / Email)
- Сваля PNG mockup за собствена употреба

---

## Може ли да вземем 3D моделите от mug3d.com?

**НЕ.** Техните модели са тяхна собственост. Използването им без разрешение е нарушение на авторски права.

**Но не ни трябват.** Имаме по-добро решение:

---

## Най-добрият подход — Three.js Procedural Geometry

Вместо да търсим GLTF модел, **строим чашата от нулата с Three.js геометрии**:

```
Чаша = CylinderGeometry (тяло)
     + TorusGeometry    (дръжка — апроксимация)
     + CircleGeometry   (дъно)
```

### Защо е по-добре от GLTF модел:

| | GLTF модел | Three.js геометрия |
|---|---|---|
| Зависимост от external файл | Да — трябва свален файл | Не — всичко в кода |
| UV mapping | Зависи от модела | Перфектен автоматично |
| Цвят на дръжка/вътре | Трудно | Лесно — отделни materials |
| Размер | 5-20 MB | ~0 (само код) |
| Контрол | Ограничен | Пълен |
| Мобилна производителност | По-бавно | По-бързо |

## Как работи текстурата (детайлно)

```
СТЪПКА 1: Офскрийн Canvas (дизайн зоната)
┌────────────────────────────────┐
│  Фон (цвят на тялото)          │  ← от color picker
│                                │
│     [ЛОГО/СНИМКА]              │  ← от FileReader
│     "Текст на клиента"         │  ← от input
│                                │
└────────────────────────────────┘
         ↓ CanvasTexture
         
СТЪПКА 2: Three.js CylinderGeometry
  - material.map = canvasTexture
  - UV координатите на цилиндъра автоматично
    "разгъват" canvas-а около чашата
         
СТЪПКА 3: Real-time update
  При всяка промяна → texture.needsUpdate = true
  → Three.js прерисува в следващия frame
```

## Интеграция с поръчка

### WhatsApp (препоръчително)
```javascript
const msg = `Здравейте, искам да поръчам персонализирана чаша:
- Цвят: ${mugColor}
- Текст: "${userText}"
- Прилагам дизайна като снимка`;

window.open(`https://wa.me/359884121606?text=${encodeURIComponent(msg)}`);
```

### Email
```javascript
window.location.href = `mailto:info@savovpro.com
  ?subject=Поръчка персонализирана чаша
  &body=${encodeURIComponent(emailBody)}`;
```

### Download PNG (клиентът изпраща файла сам)
```javascript
// Snapshot на Three.js canvas
renderer.render(scene, camera);
const link = document.createElement('a');
link.href = renderer.domElement.toDataURL('image/png');
link.download = 'savovpro-mug-design.png';
link.click();
```

## Брандиране (SAVOV PRO специфично)

- Тъмен фон (`#0a0a0a`) — същия като сайта
- Златист акцент (`#c9a227`) за бутони и highlights
- SAVOV PRO лого в хедъра
- Watermark "SAVOV PRO" в долния ъгъл на 3D canvas-а
- Съобщението в WhatsApp идва от "Конфигуратора на SAVOV PRO"
- Панелът стилово съответства на останалите конфигуратори
