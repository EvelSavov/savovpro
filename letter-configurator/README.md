# SAVOV PRO — 3D Letter & LED Lightbox Configurator

Browser CAD engine for personalized 3D letters / LED lightboxes.

## Current milestone (Phase A–D POC)

Generate printable:

- `BODY.stl` — hollow letter with solid back
- `DIFFUSER.stl` — front diffuser with fit tolerance

Units: **1 = 1 mm**. Geometry runs locally (OpenType.js + Manifold WASM).

## Dev

From repo root:

```bash
npm run letter:dev
```

Open the URL Vite prints (base path `/letter-configurator/`).
